How staff should use this

  1. Open the slot you're producing (e.g. S1 Black Gold Mala).
  2. Look at the contact sheet — pick the photographer reference closest to the Hero prompt.
  3. Open Higgsfield → upload that reference as seed image → paste the Hero prompt → generate.
  4. For each slot also generate Detail / Action / Atmosphere variants — gives you 4 images per slot for IG carousel or A/B testing.
  5. Tap Copy next to any prompt to copy the exact text.
Prompt anatomy (4 per slot): HERO the main feed shot · DETAIL macro / texture · ACTION motion / chef-or-hand moment · ATMOSPHERE wider scene / room mood.
