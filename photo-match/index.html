How to use this — 给员工的操作步骤

  1. Pick a slot (e.g. V1 "From farm to pot") from the list below.
  2. Look at the candidate contact sheet on the left to choose a strong-looking photo.
  3. Note the filename (e.g. DSC03872.JPG) from the picks list.
  4. Find the file in ~/Downloads/drive-download-20260605T021129Z-3-XXX/ on Lawrence's Mac.
  5. Open Higgsfield → upload the photo as the seed image / reference.
  6. Pick a prompt variation on the right (Hero / Detail / Action / Atmosphere) based on what shot you want.
  7. Click ⧉ Copy → paste into Higgsfield's prompt field.
  8. Pick output format: 9:16 for TikTok/Reels, 1:1 for IG feed, 4:5 for IG portrait, 16:9 for FB.
  9. Generate. Download the output. Tag it with the slot ID (V1, S6, etc.) and save to a "Higgsfield outputs" folder.
  10. Send to Lawrence for QC + caption pairing.
